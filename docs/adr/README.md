# Architecture Decision Records (ADRs)

This directory contains durable Architecture Decision Records.
We record non-obvious, binding architectural decisions here so context is preserved over time.

## ADR Index

| Number | Title | Status | Date | Linked Story |
|---|---|---|---|---|
| [0000](0000-template.md) | ADR Template | Proposed | YYYY-MM-DD | — |

## Lifecycle
- **Proposed**: Under review / consensus check.
- **Accepted**: Binding decision approved and active.
- **Superseded**: Replaced by a newer ADR (must link to superseding ADR).
