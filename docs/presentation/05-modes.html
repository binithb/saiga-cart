Two Operating Modes

AI-assisted engineering operates effectively at two distinct scales. Problems arise only when teams ask for Mode B results with Mode A tooling.

🎯
The governing rule: Specification, context, and verification must match the blast radius of the task. Local typing needs little overhead; cross-repo features require a durable shared contract.
Side-by-Side Comparison

Matching Method to Scope

Mode A

Typing Helper

Scope: Boilerplate, snippets, and genuinely local edits.

Context: Nearby code and relevant repository instructions; the human supplies the wider system model.

Verification: Focused checks appropriate to the change.

Human role: Direct the edit and review its effect.

Mode B

System-Aware Partner

Scope: Feature delivery, API refactors, and cross-repository work.

Context: Instructions, architecture, ADRs, active plans, and affected sibling repositories.

Verification: Contract-level tests, relevant suites, and human audit.

Human role: Approve boundaries, judge evidence, and authorize merge.
