Governance · 7 / 9

Human Navigator, AI Driver

Clear division of responsibility prevents both micro-management fatigue and runaway unreviewed code generation.

🧭
The irreversibility principle: Humans own the points of irreversibility (architecture choices, merge approvals, deployments). AI handles reversible drafting, refactoring, and test execution.
Division of Labor

Two Complementary Roles

Human Engineer

The Navigator

  • Sets Direction: Defines the problem, scope limits, and business goals.
  • Records Constraints: Writes ADRs and key architectural decisions.
  • Reviews Evidence: Evaluates diffs, test logs, and security implications.
  • Approves Merges: Retains final authority over git main and releases.
AI Agent

The Driver

  • Drafts Implementations: Generates code, tests, and documentation rapidly.
  • Executes & Self-Corrects: Runs compilers, linters, and tests; fixes its own errors.
  • Explores Options: Proposes candidate implementations within stated constraints.
  • Operates Reversibly: Works entirely in feature branches and draft PRs.

The Autonomy Speed Dial

Calibrate autonomy by cost of reversal: for cheap-to-undo work (scratch branches, unit test additions), let the AI run autonomously. For expensive-to-undo work (database migrations, public APIs, auth flows), gate with explicit human consensus checks.
