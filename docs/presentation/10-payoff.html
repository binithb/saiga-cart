Rollout Strategy

Four Steps to Adopt Without Overhead

Phase 1

Capture System FAQ

Write down the 3–5 things you repeatedly explain to new developers or AI sessions in a single AGENTS.md.

Phase 2

Define System Architecture

Commit a 1-page docs/architecture.md summarizing repo boundaries, contracts, and technology stack.

Phase 3

Move Active Plan to Git

Version the current sprint/increment in docs/planning/. Update plans in the same PRs that change code.

Phase 4

Prune Relentlessly

Treat docs like code: delete stale files immediately. Concise, accurate context beats voluminous prose every time.
