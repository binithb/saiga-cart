Co-location & The Planning Ladder

Keeping planning artifacts in git beside the code gives AI instant access without custom API plugins. A clean planning ladder connects multi-month goals to today's code diff.

🪜
Clear division of labor: The remote issue tracker (Jira, GitHub, GitLab, ADO) is canonical for tickets, assignments, and burndowns. The git repository is canonical for technical plans, architecture, and ADRs.
Why In Git?

The Value of In-Repo Planning

01

Zero Integration Cost

Any AI agent with the repository open can read plans, ADRs, and architectures immediately — no API tokens, browser extensions, or copy-pasting required.

02

Impossible to Diverge

Plan adjustments ride on the exact same branch and pull request as the code changes. Plan and code stay 100% synchronized in git history.

03

Survives Tool Churn

Plain markdown files outlive AI vendor switches, tracker migrations, and IDE upgrades. Your intellectual property stays permanently in your repo.
